## 🪙 What is Token Dust and Why Does it Trap SOL?

On Solana, each SPL token holding requires an **Associated Token Account (ATA)**. To persist in validator memory without eviction, each ATA locks **0.00203928 SOL** as a rent-exempt deposit.

Over months of active DeFi swaps, meme trading, and airdrops, wallets accumulate dozens or hundreds of empty or dust-filled accounts. For example:
- **50 obsolete token accounts = ~0.102 SOL (~$15.30 USD)** locked away invisibly.
- **200 accounts = ~0.408 SOL (~$61.20 USD)** trapped!

**Swap.io's Dust Sweeper** scans your wallet, liquidates residual dust balances into native SOL or USDC, closes the obsolete accounts in atomic batches, and credits the rent deposit directly back to your balance!
